# وِرْد — تجهيز نسخة أندرويد APK

هذا المشروع يحوّل صفحة HTML الأصلية إلى تطبيق Android باستخدام Capacitor، ويضيف إشعارات محلية يومية تعمل من نظام Android بعد جدولة التذكير.

## بناء APK باستخدام الهاتف فقط

1. افتح https://github.com من متصفح الهاتف وأنشئ حسابًا إن لم يكن لديك حساب.
2. أنشئ مستودعًا جديدًا (New repository)، واجعله Private أو Public حسب رغبتك.
3. فك ضغط ملف المشروع على هاتفك، ثم ارفع الملفات الأربعة الموجودة في المجلد الرئيسي إلى المستودع: `index.html` و`notifications.js` و`package.json` و`capacitor.config.json`.
4. من المستودع اختر **Add file → Create new file**، واكتب اسم الملف كاملًا: `.github/workflows/build-apk.yml`، ثم الصق محتوى ملف `build-apk.yml` الموجود داخل مجلد المشروع، واحفظه بعمل Commit.
5. افتح تبويب **Actions** داخل المستودع.
6. اختر **Build Ward Android APK** ثم اضغط **Run workflow**.
7. انتظر حتى تنتهي عملية البناء بنجاح.
8. افتح نتيجة التشغيل، وانزل إلى **Artifacts**، ثم نزّل `Ward-Android-APK`.
9. فك ضغط الملف الذي نزلته؛ ستجد `app-debug.apk`. افتحه وثبّته على هاتفك، واسمح بالتثبيت من هذا المصدر إذا طلب Android ذلك.

## ملاحظات مهمة

- أول بناء قد يستغرق عدة دقائق.
- هذه نسخة Debug للتثبيت الشخصي والاختبار، وليست نسخة متجر Google Play.
- عند فتح التطبيق لأول مرة، ادخل الإعدادات وحدد وقت التذكير واضغط «تفعيل».
- سيطلب Android إذن الإشعارات. وافق عليه. بعد ذلك يجدول النظام التذكير يوميًا حتى عند إغلاق التطبيق.
- إذا كان الهاتف يقيّد عمل التطبيقات في الخلفية، اسمح لتطبيق «وِرْد» بالإشعارات، واضبط البطارية على عدم التقييد إن لزم.
- بيانات التقدم محفوظة محليًا على الجهاز؛ لا تحذف بيانات التطبيق أو التطبيق نفسه قبل أخذ نسخة احتياطية إذا كنت تريد الاحتفاظ بتقدمك.
- لم نغيّر خطة السور أو تقسيم المهام الأصلي في ملف HTML.

## ما الذي يحتويه المشروع؟

- `index.html`: واجهة التطبيق ومنطق الخطة الأصلي.
- `notifications.js`: جسر الإشعارات المحلية في Android.
- `package.json` و`capacitor.config.json`: إعدادات البناء.
- `.github/workflows/build-apk.yml`: بناء APK تلقائيًا على GitHub Actions.
